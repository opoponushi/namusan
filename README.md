# 音の地図（Interval Map）— プロトタイプ

音程視覚化Webアプリのフロントエンド・プロトタイプ置き場です。
コアデータ（度数記号12種／インターバル色13段階）は `docs/requirements_v4.md` の確定仕様に基づいています。

## 構成

```
.
├── index.html              最新版プロトタイプ（そのままブラウザで開けます）
├── prototype/
│   ├── v01_react_baseline.jsx   最初のReact版プロトタイプ
│   └── v02.html 〜 v17.html     以降のバージョン履歴（HTML/CSS/Vanilla JS版）
└── docs/
    └── requirements_v4.md   機能要件定義書（v4）
```

## 使い方

`index.html` をブラウザで直接開くだけで動作します（ビルド不要）。
GitHub Pagesを有効にすれば、そのままプレビューURLとしても使えます。

## バージョン履歴の見方

`prototype/` 以下は開発の過程をそのまま残したものです。主な節目は以下の通り。

| バージョン | 内容 |
|---|---|
| v01 | React版の初期プロトタイプ（横方向のパネル送り） |
| v02〜v03 | 参照デザインに合わせて縦方向のワイプ演出へ変更 |
| v04〜v06 | 上昇/下降で移動方向を切り替え、単一平面トラック方式に修正 |
| v07 | スライド方向を反転 |
| v08〜v10 | インターバル色の縦アニメーション（虹彩演出）を追加・強化 |
| v11〜v13 | SF風の光の粒子→線状の光に変更、密度調整 |
| v14〜v16 | UIレイアウト整理（音声/クリーン再生ボタンの再配置、配色調整） |
| v17 | ノートパネルをすりガラス化、宇宙背景（スターフィールド）を追加 |

各バージョンの詳しい変更点は `git log` のコミットメッセージを参照してください。
